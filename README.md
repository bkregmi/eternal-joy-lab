# Spiritual React

A static React frontend scaffold for the spiritual website.

## Setup

1. Install dependencies:
   ```bash
   cd react-spiritual
   npm install
   ```

2. Run the app locally:
   ```bash
   npm start
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Notes

- This project is intentionally static and does not include server-side PHP features.
- Dynamic features such as login, database-backed mala tracking, or save-json will need a separate backend if you want them again.
